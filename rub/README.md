# Rabindra University journal public mirror

Public snapshot of https://persian.du.ac.bd/rubj/index.php/rub, prepared 26 October 2026.

- 7 published issues, 106 publicly linked article pages and 96 available article PDFs.
- Existing issue-level PDF files and original typography are included.
- Search uses the local public article metadata index.
- Login, registration, submissions and citation exports use the original OJS journal.
- This is a static snapshot; changes to the original journal require refreshing the mirror.
- No database, private OJS files, credentials or administrative tools are included.

The existing DOI Lab homepage is unchanged. Deploy through the repository's existing GitHub Pages configuration.
