# rafat

Static academic website. Open index.html or serve this folder with any static host. Assets use relative paths so this folder can also be hosted at its own domain root.

Source: https://www.du.ac.bd/faculty/faculty_details/HBEK/64
Retrieved: 2026-11-01.

Do not add a CNAME inside this folder: GitHub Pages applies CNAME at repository level. Separate domains require separate hosting or URL forwarding.

English is the default at index.html; bn.html is the complete Bengali edition. The language switch retains the current section. Both editions share style.css and app.js. English publication titles are translated or taken from the University profile; complete original citations remain available under Original citation.
