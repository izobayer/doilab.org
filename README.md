# DOI ল্যাব বাংলাদেশ

বাংলা ভাষার একটি responsive static website। কোনো package installation প্রয়োজন নেই।

`index.html` সরাসরি ব্রাউজারে খুলুন অথবা এই ফোল্ডার থেকে চালান:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

তারপর http://127.0.0.1:8765 খুলুন।

লোগো: `assets/logo.svg`। কনটেন্ট: `index.html`। রং ও লেআউট: `style.css`। প্রজেক্ট তালিকা ও ব্রিফ ডাউনলোড: `app.js`।

সাতটি প্রকল্প ও সেবার বিবরণ ব্যবহারকারীর দেওয়া তথ্য থেকে নেওয়া। যোগাযোগের ইমেইল: doilaborg@gmail.com। মোবাইল: 01521208609। প্রজেক্ট ব্রিফ ডাউনলোড করে ইমেইলে পাঠানো যায়; কোনো ফর্ম সার্ভারে পাঠানো হয় না। কোনো বাহ্যিক ফন্ট বা স্ক্রিপ্টের নির্ভরতা নেই।

বাংলা সংস্করণ: `bn.html`। হেডারের বাংলা / English বাটনে ভাষা পরিবর্তন করা যায় এবং বর্তমান সেকশন বজায় থাকে। বাংলা সংস্করণের ইন্টারঅ্যাকশন: `app-bn.js`। বাংলা ফন্ট লোকাল `assets/fonts/` ফোল্ডারে রাখা আছে।
